# MLX NLP Tutorial

A comprehensive hands-on tutorial for Natural Language Processing (NLP) using **Apple's MLX framework**, optimized for Apple Silicon GPUs via Metal.

> **Updated October 6, 2026:** MLX 0.32.3, MLX-LM 0.32.0, Transformers 5.19.0, and Sentence Transformers 6.1.0. Python 3.12+; Apple Silicon macOS 14+. Direct dependency versions are pinned in `requirements.txt`.

## 🎯 Project Overview

This project showcases three practical NLP use cases for chatbots, using **small synthetic datasets** with optional real-data downloads:

1. **Intent Classification** - Classify user commands into categories (with SNIPS and Banking77 available for further experiments)
2. **Sentiment Analysis** - Detect emotions in messages (with IMDB available for binary sentiment experiments)
3. **Text Generation** - Generate responses and provide autocomplete suggestions (using a small character-level corpus; WikiText-2 is available separately)

The training lessons use MLX; notebook 10 uses Sentence Transformers with PyTorch. The default lessons run on bundled toy data. `make setup-real` downloads larger datasets; adapt preprocessing and label counts before training on them. Example predictions below are illustrative, not measured accuracy claims.

## 🚀 Features

### 1. Intent Classification
- Classifies user input into predefined intents
- Uses LSTM-based architecture
- **Real datasets**: SNIPS (seven intents), Banking77 (13K queries across 77 intents)
- **Sample data**: 160 examples for quick testing (generated by `scripts/generate_synthetic_data.py`)
- Interactive prediction mode with confidence scores

**Example Usage:**
```
Input: "Hello there"
→ Intent: greeting (confidence: 95%)

Input: "What's the weather like"
→ Intent: question (confidence: 92%)

Input: "Turn off the lights"
→ Intent: command (confidence: 88%)
```

### 2. Sentiment Analysis
- Detects sentiment in user messages
- Sample task: negative, neutral, positive; IMDB uses two classes
- **Real dataset**: IMDB movie reviews (50K labeled reviews)
- **Sample data**: 150 reviews for quick testing (generated by `scripts/generate_synthetic_data.py`)
- LSTM with dropout for better generalization
- Returns confidence scores with probabilities

**Example Usage:**
```
Input: "I love this product"
→ Sentiment: positive
→ Probabilities: negative=2% neutral=5% positive=93%

Input: "This is terrible"
→ Sentiment: negative
→ Probabilities: negative=90% neutral=7% positive=3%
```

### 3. Text Generation
- Generates text continuations from seed text
- **Real dataset**: WikiText-2 (~2M training tokens)
- **Sample data**: A short MLX-description corpus without artificial repetition for quick testing
- Temperature-controlled sampling
- LSTM-based character-level generation

**Example Usage:**
```
Seed: "hello how are"
→ Generated: "hello how are you today"

Text: "thank you very"
→ Suggestions: much (45%), well (30%), nice (15%)
```

## Current MLX patterns and verification

The shared trainer uses mini-batches, gradient clipping, and `mx.compile` with
model, optimizer, and random state captured. It evaluates each update to bound
the lazy graph and measures metrics with dropout disabled. Pass
`compile_step=False` when debugging. Padding is excluded from LSTM readout and
Transformer attention/pooling. NanoGPT uses `mx.fast.scaled_dot_product_attention`
with a causal mask; notebook 06 retains explicit attention weights for teaching.
The positional table is a non-trainable module attribute.

Notebook 08 demonstrates QLoRA on a 4-bit model with gradient checkpointing,
prompt-loss masking, a bounded sequence length, and the tokenizer's chat template.
Its synthetic train/validation prompts are disjoint; responses are the intent
labels being evaluated. Notebook 09 is an offline retrieval/prompt construction
demo; pass a loaded tokenizer to format its messages for a specific model.

```bash
make check    # dependency install, static checks, notebook validation, unit tests
make smoke    # execute notebooks 00–07 (including 06b) and 09 with short training
# Full offline runs use the original training budgets:
.venv/bin/python scripts/check_notebooks.py --execute
```

The runner uses temporary copies so plots and weights do not alter source files.
Notebooks 08 and 10 download pretrained models and are excluded from automated
execution. Run them interactively for full fine-tuning/embedding validation.
`make setup-samples` works offline without installing ML packages. `make run`
reuses the environment until `requirements.txt` changes. Direct pins do not lock
transitive dependencies; use `python -m pip freeze` to archive a particular run.

Upstream references: [MLX compilation and random state](https://ml-explore.github.io/mlx/build/html/usage/compile.html),
[fused attention and mask conventions](https://ml-explore.github.io/mlx/build/html/python/_autosummary/mlx.core.fast.scaled_dot_product_attention.html),
[MLX-LM LoRA](https://github.com/ml-explore/mlx-lm/blob/main/mlx_lm/LORA.md).

### Make Targets

| Command          | What it does                                                  |
|------------------|---------------------------------------------------------------|
| `make setup`     | `venv + install + sample data` — first-run convenience       |
| `make run`       | Launch Jupyter inside the venv                                |

### Training with Real Datasets

**Download datasets:**
```bash
# All real datasets via the Makefile (creates data/imdb, data/snips, …)
make setup-real

# Or directly via the Python script
python scripts/download_datasets.py --imdb     # Sentiment analysis
python scripts/download_datasets.py --snips    # Intent classification
python scripts/download_datasets.py --wikitext # Text generation
```

**Train models in notebooks:**
Downloading a dataset does not switch a notebook to it. Follow the
[real-data adaptation steps](PRODUCTION_README.md#train-on-real-data) to update
loading, label counts, and preprocessing. The training lessons cover:
- Dataset loading and preprocessing
- Model training with progress visualization
- Evaluation and testing
- Interactive predictions

**Available Datasets:**
- **IMDB**: 50K movie reviews (sentiment)
- **SNIPS**: 13,784 training and 700 validation queries (7 intents)
- **Banking77**: 13K banking queries (77 intents)
- **WikiText-2**: ~2M training tokens (generation)

**See [notebooks/README.md](notebooks/README.md) for complete learning guide**

## 🔧 Technical Details

### Model Architectures

The shared LSTM models and trainer live in `notebooks/mlx_nlp_utils.py`.
The Transformer classifier and NanoGPT architectures are defined in notebooks
05 and 07 so the lessons can explain their construction.

**Intent Classifier:**
- Embedding dimension: 32
- LSTM hidden size: 64
- 3 output classes
- Training: 30 epochs with Adam (lr 0.01, see notebook 01)

**Sentiment Analyzer:**
- Embedding dimension: 64
- LSTM hidden size: 128
- Dropout: 0.3
- 3 output classes
- Training: 100 epochs with Adam (lr 0.001, see notebook 02)

**Text Generator:**
- Embedding dimension: 128
- LSTM hidden size: 256
- Sequence length (training): 5 characters (sliding window)
- Training: 10 mini-batch epochs with Adam (lr 0.001, batch size 64; see notebook 03)

### MLX Framework Benefits

- **Native Apple Silicon support** - Runs on M1/M2/M3/M4 GPU via Metal
- **Efficient memory usage** - Optimized for unified memory architecture
- **Low latency** - On-device inference without cloud dependency
- **Familiar API** - NumPy-like interface with PyTorch-style modules

**🔰 Total Beginner? (6 hours)**

2. `notebooks/01_Intent_Classification.ipynb` (60 min) — complete tutorial
3. `notebooks/02_Sentiment_Analysis.ipynb` (75 min) — build on classification
4. `notebooks/03_Text_Generation.ipynb` (90 min) — the trickier objective
5. `notebooks/04_Complete_Pipeline.ipynb` (120 min) — full integration
6. `notebooks/05_Transformer_Classifier.ipynb` (45 min) — replace LSTM with a Transformer
7. **Advanced:** `notebooks/06_Attention_Mechanism.ipynb` and `notebooks/07_Build_NanoGPT.ipynb` to understand Transformers end-to-end.
8. **Pro:** `notebooks/08_Fine_Tuning_with_LoRA.ipynb` — fine-tune a small Llama.
9. **Architect:** `notebooks/09_RAG_from_Scratch.ipynb` — toy RAG walkthrough.
10. **Expert:** `notebooks/10_Embeddings_Deep_Dive.ipynb` — sentence-embedding trade-offs (note: this one jumps out of MLX into `sentence-transformers`).

Run cells in order from the Jupyter session launched by `make run`. Depending
on the lesson, interactive runs write plots, saved weights, or LoRA adapters.
Notebooks 08 and 10 also download models into the Hugging Face cache.

**🚀 Advanced Developer?**

2. Review `notebooks/mlx_nlp_utils.py` for the shared model implementations
